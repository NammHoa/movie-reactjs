# Menu 7 mục Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menu 7 mục trên máy tính, menu ba gạch trên điện thoại, và trang "Đang phát triển" cho 5 mục chưa làm.

**Architecture:** Danh sách mục và quy tắc "mục nào được tô" là hàm thuần trong `client/src/lib/menu.js`, có test. Menu máy tính, menu điện thoại, router và trang "Đang phát triển" cùng đọc danh sách đó, nên thêm một tính năng sau này chỉ cần sửa một chỗ.

**Tech Stack:** React 19, React Router 7, Tailwind CSS 4, `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-26-nav-menu-design.md`

## Global Constraints

- Không thêm thư viện. Không sửa server, database, trang quản trị. Biểu tượng ba gạch và ✕ vẽ bằng SVG trong code.
- Thứ tự và tên: Mua vé, Movie Talk, Rạp chiếu phim, Tin mới & Ưu đãi, Shop, De Coin, Quảng cáo & Thuê rạp. Hiện in hoa bằng CSS.
- Mốc đổi bố cục: 1024px (`lg`). Vạch màu cát `#ddd3b5`. Mỗi dòng trong menu điện thoại cao ít nhất 44px.
- Chỉ mượn bố cục: không dùng logo, hình, nội dung hay tên riêng của Lotte.
- Kiểm ở 320, 375, 1024, 1280px với khách, người dùng tên rất dài, admin: không tràn ngang, mọi mục bấm được.
- Giao diện tiếng Việt (trừ tên riêng), commit tiếng Anh, người dùng là người commit. Kiểm trên trình duyệt chỉ dùng database `_test`.

### Task 1: Danh sách mục và trang "Đang phát triển"

**Files:**
- Create: `client/src/lib/menu.js`, `client/src/pages/user/ComingSoon.jsx`
- Modify: `client/src/App.jsx`
- Test: `client/test/menu.test.js`

**Interfaces:**
- Produces: `MENU: Array<{ label: string, to: string, comingSoon?: true }>`; `activeMenu(pathname: string): string | null` (trả `to` của mục cần tô); `<ComingSoon title={string} />`.

- [ ] **Step 1: Viết test**

```js
import test from 'node:test'
import assert from 'node:assert/strict'
import { MENU, activeMenu } from '../src/lib/menu.js'

test('đủ 7 mục đúng thứ tự', () => {
  assert.deepEqual(MENU.map((m) => [m.label, m.to]), [
    ['Mua vé', '/#movie-list'],
    ['Movie Talk', '/movie-talk'],
    ['Rạp chiếu phim', '/cinemas'],
    ['Tin mới & Ưu đãi', '/news'],
    ['Shop', '/shop'],
    ['De Coin', '/de-coin'],
    ['Quảng cáo & Thuê rạp', '/rent'],
  ])
})

test('5 mục chưa làm', () => {
  assert.deepEqual(MENU.filter((m) => m.comingSoon).map((m) => m.to), ['/movie-talk', '/news', '/shop', '/de-coin', '/rent'])
})

test('tô mục của trang đang xem', () => {
  assert.equal(activeMenu('/'), '/#movie-list')
  assert.equal(activeMenu('/cinemas'), '/cinemas')
  assert.equal(activeMenu('/cinemas/abc123'), '/cinemas')
  assert.equal(activeMenu('/news'), '/news')
  assert.equal(activeMenu('/news/'), '/news')
})

test('trang không thuộc mục nào thì không tô', () => {
  for (const path of ['/movies/abc', '/movie', '/newsletter', '/booking/1', '/login', '/profile', '/my-tickets', '/admin', '/admin/cinemas']) {
    assert.equal(activeMenu(path), null, path)
  }
})
```

- [ ] **Step 4:** Chạy lại. Expected: PASS toàn bộ.
- [ ] **Step 5:** `ComingSoon.jsx`: tiêu đề là `title`, dòng "Tính năng đang được phát triển.", link **Mua vé** (`/#movie-list`) và **Về trang chủ** (`/`). Trong `App.jsx`, tạo route từ các mục `comingSoon` của `MENU`, mỗi route có `key={to}`.
